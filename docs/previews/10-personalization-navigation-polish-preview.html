Design handoff · v1.0

One true line, then the work — and the chrome steps aside.

Today opens with a plain heading that names the lifter and says what today holds; Settings gains Light, Dark, and System (default), applied instantly and remembered by the account; and below md the bottom bar gives way to a menu button and a sheet, while the desktop rail stays exactly as it is. Check every greeting against "is this true about today, and would it embarrass a coach-free tool?" Use the Light / Dark switch to flip every product surface.

Note This preview is a rendering of the design, not product code. The app is built with Tailwind and shadcn/ui against the theme in globals.css; nothing here is copied into it. Mock data only.

What these screens are built to respect

The design commitments a reviewer should check the frames above against.

The greeting

  • A line, not a voice. No emoji, no ! or ?, no advice, no encouragement, no persona, no chat input — a heading and nothing behind it.
  • True about today only. Planned, underway, done, rest, no plan, first visit — never a missed day, never tomorrow, never a schedule that doesn't exist.
  • The account's clock. Salutation and the 9 pm–4 am late-night family use the stored timezone; no zone → Hello and no late-night.
  • Stable. Same account + situation + local date → same sentence; it moves only when the day, the situation, or the time band does.
  • Degrades quietly. No first name → the name drops out. Long session names wrap.

Appearance and navigation

  • Settings only. Light · Dark · System, System by default; no toggle in the header, on Today, or on a logging card.
  • Instant, everywhere, saved. The app switches on tap, the account remembers it, a failure reverts with an inline error.
  • System is live. Following the device means following it while open, not freezing its value.
  • Phone: content first. No bottom bar; a sticky header with one menu button; thumb bars at the bottom edge at 44px.
  • Sheet gets out of the way. Same six destinations + Settings; a choice, ×, scrim, Escape, or route change closes it.
  • Desktop untouched. Rail, items, active style, header — exactly as before.
