Design handoff · v1.0

The weight carries, the reps are always yours.

One set has fields at a time. Its weight is offered — from last time for the first set, then from the set just logged — and its reps are always typed. Nothing is history until the lifter presses Log set; a logged set is plain text with a check. Check every frame against one rule: a box is a draft, a plain number is history, and the card never has more controls than it does today. Use the Light / Dark switch to flip every product surface.

Note This preview is a rendering of the design, not product code. The app is built with Tailwind and shadcn/ui against the theme in globals.css; nothing here is copied into it. Mock data only: Push Day 1 at Downtown Gym, Tuesday Oct 20, 2026, last done Tuesday Oct 13.

What these screens are built to respect

The commitments a reviewer should check the frames above against.

History stays true

  • A box is a draft; a plain number is history. Every logged row is text with a check; every prefilled value sits inside a box with its source caption.
  • Nothing is written without Log set. No auto-log, no auto-complete, no row filled ahead of the active one, no advance before the write confirms.
  • Reps are never offered. Only the weight carries; the Progress +5 and the deload 90% stay display-only.
  • Machines and cables stay at their gym. Last time here, or First time on this at …; never another gym's number.
  • Bodyweight stays reps only, and correcting a set uses History's own confirmed dialog.

Fewer taps, no more controls

  • One active row. Upcoming sets are quiet dashes; the card shows fewer controls than today in every state (12 → 8).
  • Focus follows the lifter. Nothing focuses on load; after Log set the cursor is in the next reps; after the last set, on Next.
  • Thumb-sized. 48px set fields, 44px Log set, rows, and runner buttons; one line at 320px.
  • No rest timer, no RIR, no new buttons, no sticky bar, no auto-advance between exercises.
  • Hold looks like nothing, tags unchanged; light and near-black dark via tokens only.
