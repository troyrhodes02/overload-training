Design handoff · v1.1

The lift's logbook, kept honest — records, not rewards.

The existing exercise page becomes the exercise's history: Next time (the engine's call and why), Records (best set, its e1RM estimate, heaviest weight, rep records), the Trend (e1RM or actual load), every Session with the call it led to, and the Goals set on the lift. Nothing is stored and nothing new is decided: every figure comes from the logged sets through the existing engine, e1RM, and Goals rules. Check every frame against one rule: a machine's numbers never leave the gym they were lifted at. Use the Light / Dark switch to flip every product surface.

A rendering of the design for review — not product code. The app is built with Tailwind and shadcn/ui against globals.css.

02

Records, not rewards (Journey B, AC-3)

Best set is what was lifted; Best e1RM is its estimate and says so. Heaviest is a real completed set. Rep records list a load only where its reps beat every heavier load's best, so a lighter, longer set never reads as 'better'. No badges, icons, or colour.

What these screens are built to respect

The commitments a reviewer should check the frames above against.

Only what the logged sets can back up

  • Every record, point, and call is computed on read from the logged sets as corrected; nothing is stored, so a correction flows through on the next read.
  • An estimate always says it is one: Best e1RM is labelled estimate and shows the set it came from; actual sets show weight × reps.
  • The calls are the engine's, run on the history up to each session; the newest counted one is the current call. Nothing is invented for a gap.
  • Machines and cables: one gym per page, named in every heading. No all-gyms machine figure exists.
  • Missing is not zero: no history is a sentence; one session has no chart and no call.

Records, not rewards

  • No badges, icons, colours, streaks, or animation on any record. Progress and deload colours stay inside the engine's tags.
  • Hold is a muted word in the Call column, never a badge; Next time keeps its muted lines.
  • Read-only: viewing, switching gym or chart, and expanding sessions write nothing — no set, weight, baseline, goal, or plan.
  • Archived exercises and gyms keep their history; only create-new actions disappear.
  • Phone first: a list, not a wide table; 320px wraps, nothing truncates; light and near-black dark via tokens.
