# Preview fonts

`inter-latin-variable.woff2` — **Inter** (latin subset, variable weight 100–900), the same file `next/font/google` serves to the app. It is vendored here only so UI previews in `docs/previews/` open offline with the app's real typeface. The application does not load it from here.
